
# Future of Software Engineering

Welcome to the **Future of Software Engineering** presentation by James Gress. This presentation explores the evolution of software engineering in the age of AI, highlighting key milestones, emerging technologies, and the transformative impact of AI on development workflows.

# Viewing the Presentation
https://jmgress.github.io/futureofswe/

The deck is plain HTML/CSS/JS (no build step). To run it locally, open `index.html` in a browser or serve the repo root:

```sh
python3 -m http.server 8000
# then open http://localhost:8000/
```

Press `?` in the deck for keyboard shortcuts (arrows to navigate, `S` for speaker notes, `D` for light/dark mode, `F` for fullscreen). Use the browser's Print dialog to export a PDF.

Edit slides and speaker notes in `index.html`, styling in `deck.css`, and navigation in `deck.js`. Images live in `slides/img/`.
